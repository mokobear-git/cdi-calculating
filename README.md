# CDI 採点アプリ

Children's Depression Inventory（CDI）日本語版の採点用Webアプリ。
各項目（27問）で最もあてはまる文章を選択すると、合計点（0–54）を自動算出する。

- 単一HTML（`index.html`）、依存なし
- 項目9（希死念慮）に1点以上の回答がある場合、警告を表示
- 入力内容は端末内のみで処理（送信・保存なし）

## 注意
- 本ツールは採点補助であり、診断を行うものではない。
- 項目23–27は原版PDFに得点の印字がなく、標準CDIの採点方向に準拠した。
- 原版：Kovacs M. (1982) Children's Depression Inventory.
